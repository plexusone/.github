## [v0.2.0] - 2026-10-04 ([`448b5d1`](https://github.com/plexusone/.github/commit/448b5d1))

### Highlights

- Free SAST and SCA without GitHub Advanced Security: new `go-sast-gosec` and `go-sca-govulncheck` reusable workflows (no code-scanning upload, so they work on private repos)
- Reusable TypeScript CI and lint workflows, a reusable MkDocs deployment workflow, and a reusable Go dependency auto-merge workflow
- Multi-module (matrix) support and a centralized golangci-lint config across the shared Go workflows

### Added

- `go-sast-gosec.yaml`: reusable gosec static-analysis workflow (fails on findings; no GHAS required) ([`448b5d1`](https://github.com/plexusone/.github/commit/448b5d1))
- `go-sca-govulncheck.yaml`: reusable govulncheck vulnerability-scan workflow (OSV-based, schedule-friendly) ([`dc8d8b7`](https://github.com/plexusone/.github/commit/dc8d8b7))
- Shared TypeScript CI and lint workflows ([`abd544d`](https://github.com/plexusone/.github/commit/abd544d))
